# 通用 N 维卡尔曼滤波器

## 问题定义

1D 卡尔曼滤波器估计 2 元素的状态 ``[position, velocity]ᵀ``，使用固定的运动模型和固定的观测矩阵。在实际定位问题中，状态可能有很多维度 — 2D 或 3D 的位置和速度、传感器偏置、钟差 — 而观测可能只覆盖状态的子集。

本节将线性卡尔曼滤波器泛化到任意状态维度 *n* 和测量维度 *m*（*m* ≤ *n*）：

```text
x: (n, 1) — 状态向量
z: (m, 1) — 观测向量
```

## 状态变量和维度

通用卡尔曼滤波器的矩阵维度：

```text
x: (n, 1)    状态向量
P: (n, n)    误差协方差
F: (n, n)    状态转移矩阵
H: (m, n)    观测矩阵
Q: (n, n)    过程噪声协方差
R: (m, m)    观测噪声协方差
K: (n, m)    卡尔曼增益
```

对于 *d* 维匀速模型，状态排列为位置在前、速度在后：``[p₁ … p_d, v₁ … v_d]ᵀ``，故 *n* = 2·*d*。``H`` 矩阵通常只观测位置（``H = [I_d, 0_d]``），所以 *m* = *d*。

## 数学公式

公式与 1D 情况相同，仅矩阵尺寸不同：

```text
x_pred = F x
P_pred = F P Fᵀ + Q

residual = z - H x_pred
S = H P_pred Hᵀ + R
K = P_pred Hᵀ S⁻¹
x_upd = x_pred + K residual
A = I - K H
P_upd = A P_pred Aᵀ + K R Kᵀ
```

最后一行是真正的 Joseph 协方差更新。在精确最优卡尔曼增益下，它与
``(I - K H) P_pred`` 代数等价，但其对称结构对浮点舍入误差更稳健。

代码中使用 ``np.linalg.solve`` 计算卡尔曼增益：

```python
K = np.linalg.solve(S.T, (P @ H.T).T).T
```

## 匀速模型的块矩阵形式

对于 *d* 维空间、时间步长 *dt*：

```text
    ┌         ┐
F = │ I_d  dt·I_d │
    │ 0_d    I_d  │
    └         ┘

    ┌         ┐
H = │ I_d  0_d │   （仅位置观测）
    └         ┘
```

如果位置和速度都观测（如 ``KalmanFilter1D``），则 ``H = I_{2d}``，*m* = *n*。

## 推导轮廓

1. 从 1D 卡尔曼滤波公式出发。
2. 将硬编码的 ``(2, 1)`` 和 ``(2, 2)`` 替换为维度变量。
3. 在构造时从 ``x.shape[0]`` 推断 *n*，从 ``H.shape[0]`` 推断 *m*。
4. 使用相同的 predict / update 逻辑 — 线性代数适用于任何兼容的维度。

## 与 KalmanFilter1D 的关系

``KalmanFilter1D`` 是一个具体的特例：*n* = 2, *m* = 2，位置和速度都直接观测。通用 ``KalmanFilter`` 在相同矩阵初始化时能完全复现其数值结果（测试套件已做交叉验证）。

保留 ``KalmanFilter1D`` 作为学习阶梯 — 它的小尺寸、硬编码形状让公式容易理解。当问题需要多个空间维度或部分状态观测时，迁移到 ``KalmanFilter``。

## 常见面试问题

- 测量维度 *m* 与状态维度 *n* 的关系是什么？如果 *m* < *n* 会怎样？
- 如果 ``H`` 不是列满秩，系统是否可观测？
- 为什么 ``Q`` 通常是块对角的（位置 / 速度）？
- 如何修改 ``F`` 以支持恒定加速度模型？
- ``P`` 的迹能告诉我们滤波器的什么信息？
- 如何处理传感器以极坐标形式给出位置观测？ （这引出了 EKF。）

## 常见错误

- 忘记 ``H`` 的形状是 ``(m, n)`` 而不是 ``(n, n)`` — ``R`` 必须匹配 *m* 而非 *n*。
- 把状态向量写成 ``(n,)`` 而非 ``(n, 1)``。
- 根据测量维度而不是状态维度来设置 ``Q``。
- 将 1D 的噪声参数直接用于 2D/3D 而不做缩放（Q 和 R 是每个维度的值）。
- 当 *m* ≪ *n* 且未观测状态没有被系统动力学激励时，期望滤波器效果良好。
