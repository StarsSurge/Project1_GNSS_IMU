# 扩展卡尔曼滤波器 (EKF)

## 问题定义

线性卡尔曼滤波器假设运动模型 ``f`` 和观测模型 ``h`` 都是状态的线性变换。许多真实传感器 — GNSS 伪距、距离-方位雷达、单目相机 — 产生的观测量是状态的非线性函数：

```text
x_k = f(x_{k-1}) + w       （运动）
z_k = h(x_k) + v            （观测）
```

扩展卡尔曼滤波器通过在每一步围绕当前状态估计进行线性化来处理这些非线性。

我们的示例是 **2D 距离-方位角目标跟踪**：位于已知位置的传感器测量到运动目标的距离 ``r`` 和方位角 ``θ``。两者都是目标笛卡尔坐标的非线性函数。

## 状态变量和维度

2D 距离-方位角 EKF 的状态：

```text
x = [px, py, vx, vy]ᵀ,  dim(x) = 4 × 1
```

观测：

```text
z = [r, θ]ᵀ,  dim(z) = 2 × 1
```

矩阵：

```text
P: 4 × 4,  状态误差协方差
Q: 4 × 4,  过程噪声协方差
R: 2 × 2,  观测噪声协方差
K: 4 × 2,  卡尔曼增益
F_jac(x): 4 × 4  （线性化运动模型雅可比）
H_jac(x): 2 × 4  （线性化观测雅可比）
```

## 数学公式

### 线性化

每一步 EKF 在当前估计 ``x̂`` 处使用一阶泰勒展开进行线性化：

```text
F = ∂f/∂x |_{x̂}        状态转移雅可比
H = ∂h/∂x |_{x̂}        观测雅可比
```

### 预测

```text
x_pred = f(x)                   （非线性传播）
P_pred = F P Fᵀ + Q             （线性化协方差传播）
```

### 更新

```text
z_pred = h(x_pred)              （预测观测）
residual = residual_fn(z, z_pred)（新息 / 创新）
S = H P_pred Hᵀ + R             （新息协方差）
K = P_pred Hᵀ S⁻¹               （卡尔曼增益）
x_upd = x_pred + K residual     （状态修正）
A = I - K H
P_upd = A P_pred Aᵀ + K R Kᵀ   （Joseph 协方差更新）
```

对于欧氏空间观测，``residual_fn(z, z_pred) = z - z_pred``。周期观测必须使用
符合流形性质的残差。本例将方位角残差归一化到 ``[-π, π)``，避免跨越分支时
把很小的角度差错误解释为接近 ``2π``。

## 距离-方位角观测模型

传感器位于 ``(sx, sy)``，目标位于 ``(px, py)``：

```text
r   = √((px - sx)² + (py - sy)²)
θ   = atan2(py - sy, px - sx)
```

``h = [r, θ]ᵀ`` 对 ``x`` 的解析雅可比：

```text
H = ┌                              ┐
    │  dx/r   dy/r   0   0 │
    │ -dy/r²  dx/r²  0   0 │
    └                              ┘

其中 dx = px - sx, dy = py - sy, r = √(dx² + dy²)
```

## 推导轮廓

1. 从非线性系统方程出发。
2. 在当前估计处用一阶泰勒展开进行线性化。
3. 用线性化的 ``F`` 和非线性的 ``f`` 进行标准的线性卡尔曼预测。
4. 用线性化的 ``H`` 和非线性的 ``h`` 计算新息，进行标准卡尔曼更新。
5. 卡尔曼增益 ``K`` 由线性化的 ``H`` 和当前 ``P`` 计算得出。

## EKF 的局限性

1. **一阶近似**：EKF 只保留泰勒展开的线性项。强非线性可能导致发散。
2. **雅可比维护**：解析雅可比容易出错；数值雅可比较慢。两者都必须正确滤波器才能工作。
3. **一致性**：当线性化误差较大时，EKF 可能变得过度自信（协方差 ``P`` 低估了真实误差）。
4. **初始化敏感性**：初始猜测太差意味着滤波器围绕一个不好的点线性化，可能导致发散。
5. **坐标系依赖性**：在笛卡尔坐标和极坐标下的线性化可能给出不同结果。

## 与 ESKF（误差状态卡尔曼滤波器）的关系

EKF 直接对完整状态进行线性化。误差状态卡尔曼滤波器（ESKF）—— 本项目的下一步 —— 将名义状态（非线性传播）与小误差状态（线性传播）分离。这是 GNSS/IMU 融合的标准方法，因为：

- 误差状态始终很小 → 线性化更准确。
- 姿态在名义状态中用四元数参数化，在误差状态中用 3 自由度小角度向量参数化。
- 每次修正后误差状态可以归零。

## 常见面试问题

- 为什么要线性化？如果直接用非线性 ``h`` 进行卡尔曼更新会怎样？
- 解析雅可比和数值雅可比有什么区别？各适用于什么场景？
- EKF 在什么条件下会发散？
- EKF 与无迹卡尔曼滤波器（UKF）相比如何？与粒子滤波器呢？
- 为什么 Joseph 形式 ``A P Aᵀ + K R Kᵀ`` 比简化形式
  ``(I - KH) P`` 更适合数值计算？
- 在距离-方位角示例中，为什么远距离时方位角噪声影响更大？
- 当目标恰好在传感器位置时，雅可比会怎样？如何处理？

## 常见错误

- 在预测之前忘记在当前状态处重新计算 ``F``（使用了旧的雅可比）。
- 在整个过程使用常值雅可比 — 必须每一步重新计算。
- 没有检查 ``h(x)`` 和 ``z`` 的维度是否一致。
- 使用 ``arctan2`` 时不检查象限约定。
- 直接相减周期角度，没有将残差归一化到主值区间。
- 计算复合变换的 ``F_jac`` 时忘记链式法则。
- ``R`` 设置得太小 — 当观测噪声被低估时，EKF 会过于相信线性化误差。
- 初始 ``P`` 设置得太小 — 滤波器拒绝新观测，收敛很慢或根本不收敛。
