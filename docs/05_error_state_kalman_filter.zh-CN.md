# 误差状态卡尔曼滤波 (ESKF) —— GNSS/IMU 松耦合

## 问题定义

在 GNSS/IMU 组合导航中，我们有：

- **IMU**：高频（200 Hz）的角速度增量和速度增量，短期精度高但随时间漂移
- **GNSS**：低频（1 Hz）的绝对位置观测，无漂移但有噪声

需要设计一个滤波器，用 IMU 做高频预测、GNSS 做低频修正，输出连续平滑的位置、速度和姿态。

**为什么要用误差状态（ESKF）而不是直接用 EKF？**

直接用 EKF 估计完整状态时，状态量本身数值很大（位置几千米、速度十几米每秒），
而误差总是很小的（位置误差几十厘米、速度误差几厘米每秒、姿态误差零点几度）。
在"小量"上做线性近似，比在"大量"上做线性近似精确得多。

```text
ESKF 的核心思想：
    标称状态 → 用完整的非线性模型传播（可以累加大量，不怕积分误差）
    误差状态 → 用线性化模型传播协方差（始终是 "小量 + 小量"，线性近似准确）
    GNSS 更新 → 在误差状态上做卡尔曼更新（残差也是小量）
    注入 + 重置 → 修正标称状态后，误差状态归零，协方差保留
```

## 双状态架构

### 标称状态 (Nominal State) — 16 自由度

这是"你认为的"真实状态，用完整非线性方程传播：

```text
x_nom = [p, v, q, b_a, b_g]

p   : 位置 (NED 坐标系)     3×1  [m]
v   : 速度 (NED 坐标系)     3×1  [m/s]
q   : 姿态四元数 (body→nav) 4×1  无单位
b_a : 加速度计零偏          3×1  [m/s²]
b_g : 陀螺仪零偏            3×1  [rad/s]
```

### 误差状态 (Error State) — 15 自由度

真实状态与标称状态之间的微小差异，**始终接近零**：

```text
δx = [δp, δv, δθ, δb_a, δb_g]

δp   : 位置误差   3×1  [m]
δv   : 速度误差   3×1  [m/s]
δθ   : 姿态误差   3×1  [rad]   ← 用 3 维小角度表示，而非 4 维四元数
δb_a : 加速度计零偏误差  3×1  [m/s²]
δb_g : 陀螺仪零偏误差    3×1  [rad/s]
```

**重要**：姿态在标称状态中是 4 维四元数，在误差状态中是 3 维小角度向量。
这是 ESKF 的关键设计——用最小的参数化描述误差，避免协方差矩阵冗余和奇异性。

```text
标称状态 16 维 + 误差状态 15 维 → 总共 31 个变量
但协方差矩阵只在 15 维误差状态上维护 → P: 15×15
```

## IMU 误差模型 —— 完整分类

### A. 系统性误差（确定性，可标定补偿）

| 误差类型 | 符号 | 单位 | 来源 | 可补偿性 |
|---------|------|------|------|:--:|
| **零偏 (Bias)** | b_a, b_g | m/s², rad/s | 传感器固有偏置, 通电后缓慢漂移 | 可在线估计 (ESKF 状态) |
| **比例因子 (Scale Factor)** | s_a, s_g | ppm | 输出值与真实值的线性比例偏差 | 可在 ESKF 状态中估计 |
| **交轴耦合 (Misalignment)** | m_xy, m_xz, ... | rad | 三轴不完全正交, 一个轴的运动会泄漏到另一轴 | 出厂标定后固定 |
| **非线性** | — | % | 大输入时的非线性响应 | 通常在规范量程内可忽略 |
| **g 灵敏度** | — | °/h/g | 加速度对陀螺仪输出的影响 | MEMS-IMU 可能显著 |

### B. 随机误差（不可预测，仅统计描述）

传感器的随机噪声用 **Allan 方差** 分析，典型噪声分为五类：

| 噪声类型 | Allan 斜率 | 物理含义 | 在 Q_d 中的方差 |
|---------|:--:|------|------|
| **角度/速度随机游走** (ARW / VRW) | −1/2 | 白噪声积分：高频随机抖动 | σ²·I·dt² |
| **偏置不稳定性** (Bias Instability) | 0 | 偏置在长时间内的缓慢漂移幅度 | 由 σ_ba²·I·dt 建模 |
| **速率随机游走** (Rate Random Walk) | +1/2 | 偏置本身的随机游走驱动 | σ²·I·dt |
| **速率斜坡** (Rate Ramp) | +1 | 非常缓慢的确定性漂移（老化） | 通常忽略 |
| **量化噪声** (Quantization) | −1 | A/D 转换的离散化误差 | 通常忽略 |

### C. 测量方程（含比例因子和交轴耦合）

**完整形式：**

```text
陀螺仪:  Δθ_meas = (I + S_g + M_g) · Δθ_true + b_g·dt + n_g·√dt
加速度计: Δv_meas  = (I + S_a + M_a) · Δv_true  + b_a·dt + n_a·√dt
```

其中：

```text
S = diag(s_x, s_y, s_z)          比例因子对角阵 (每个轴的灵敏度偏差)

    ┌              ┐
    │  0    m_xy  m_xz │
M = │ m_yx   0    m_yz │         交轴耦合反对称近似
    │ m_zx  m_zy   0   │
    └              ┘
```

### D. 零偏的时间演化模型

零偏本身**不是常数**，随时间和温度缓慢变化。标准模型是**一阶高斯-马尔可夫过程**（介于白噪声和随机游走之间）：

```text
ḃ(t) = −(1/τ)·b(t) + w(t)

τ   : 相关时间 (correlation time) — 偏置的"记忆长度"
w(t): 驱动白噪声, σ² = 2·σ_b²/τ

极限情况:
  τ → ∞ : 纯随机游走 (ḃ = w, 偏置漂走不回头)
  τ → 0 : 白噪声 (偏置无记忆, 逐历元独立)
```

工程上 τ 通常取几小时到几天。对于短时车载导航（几十分钟），
**简化为纯随机游走模型 (τ → ∞)** 是安全的：

```text
ḃ_g = n_bg    ← 当前 ESKF 采用此简化
ḃ_a = n_ba
```

### E. 当前数据集的 IMU 噪声参数

Leador-A15 是战术级 MEMS-IMU，典型参数：

```text
陀螺仪:
  ARW (角度随机游走)   : 0.05 °/√h  ≈ 2.5e-4 rad/s/√Hz
  偏置不稳定性          : 0.5 °/h    ≈ 2.4e-6 rad/s
  偏置随机游走          : 0.1 °/h²   ≈ 1.3e-10 rad/s/√Hz

加速度计:
  VRW (速度随机游走)   : 0.05 m/s/√h ≈ 8.3e-4 m/s²/√Hz
  偏置不稳定性          : 50 μg      ≈ 4.9e-4 m/s²
  偏置随机游走          : 10 μg/√h   ≈ 4.9e-8 m/s²/√Hz
```

这些参数用于构造 Q_d 矩阵中的噪声项。

## INS 精确机械编排 —— 双子样圆锥/划桨补偿

机械编排的根本挑战：**IMU 测量的是旋转坐标系下的增量，
而我们需要的是导航坐标系下的导航状态**。一个 dt 内如果
载体有角运动，body 系在旋转 → 速度增量在 body 系下测的
方向在变化 → 简单的 `C_b^n @ Δv` 会引入误差。

### 三大不可交换误差

#### 1. 圆锥效应 (Coning)

```
现象:  两个正交轴上做同频率角振动 (比如 X 和 Y 都小幅摆动)
       在第三轴 (Z) 会产生一个常值旋转 —— 即使 Z 轴没有净角速度！

物理图像: 一个圆锥在桌上滚动, 接触点绕桌面画圈,
          但圆锥本身绕自己的 Z 轴有个净转动

后果:   姿态角 (尤其是航向) 会虚假地匀速漂移
量级:   在高振动环境下可达 °/h 级别
```

#### 2. 划桨效应 (Sculling)

```
现象:  角振动 + 线振动 = 虚假的常值速度
       (物理上类似划桨: 手摇动桨柄 [角], 桨片划水 [线],
        船获得一个稳定的前进速度)

后果:  速度估计出现常值偏差, 积分后位置漂移
量级:  振动环境下可达 cm/s 级, 10 秒后位置误差分米级
```

#### 3. 旋转效应 (Rotation Effect)

```
现象:  速度增量 Δv 是在 body 系下测的,
       dt 内 body 系在旋转 → 在 dt 前测量的增量
       和 dt 后测量的增量, 对应不同的"方向"

      简单地把 Δv 的起点和终点都当成同一个 body 系方向 →
      忽略了"旋转过程中速度方向也在转"这个事实

后果:  同划桨效应, 速度误差
```

### 双子样算法 (Two-Subsample Algorithm) 的数学原理

核心思想：把一个导航计算周期 T 分成两个子样窗口 `[t, t+T/2]` 和
`[t+T/2, t+T]`，在每个子样窗口内假设角速度是线性变化的，
然后在两个窗口间做旋转的**叉积交叉项**补偿。

设 Δθ₁, Δθ₂ 为前后半周期的角度增量，Δv₁, Δv₂ 为速度增量。
总增量：

```text
Δθ = Δθ₁ + Δθ₂                       总角度增量
Δv = Δv₁ + Δv₂                       总速度增量
```

**圆锥补偿项** — 加到总角度增量上：

```text
Δθ_coning = (2/3) · (Δθ₁ × Δθ₂)     ← 交叉积的 2/3
Δθ_corrected = Δθ + Δθ_coning
```

物理含义：如果两个半周期的旋转轴不一致（叉积 ≠ 0），
说明载体在做圆锥运动 → 补偿虚假的净旋转。

**划桨补偿项** — 加到总速度增量上：

```text
Δv_scul = (2/3) · (Δθ₁ × Δv₂ + Δv₁ × Δθ₂)
Δv_corrected = Δv + Δv_scul
```

物理含义：角振动 × 后半个速度增量 + 速度增量 × 后半个角振动 = 划桨效应。

**旋转效应补偿** — 也加到速度增量上：

```text
Δv_rot = (1/2) · (Δθ × Δv)          ← 平均旋转 × 总速度增量
Δv_corrected = Δv_corrected + Δv_rot
```

物理含义：dt 内的平均公转把速度增量"带歪"了多少。

### 完整的双子样机械编排（伪代码）

```
输入: Δθ₁, Δθ₂, Δv₁, Δv₂, dt=T/2 (每个子样的时长)

① 计算总增量
  Δθ = Δθ₁ + Δθ₂
  Δv = Δv₁ + Δv₂

② 圆锥补偿
  Δθ = Δθ + (2/3)·(Δθ₁ × Δθ₂)

③ 划桨补偿
  Δv_scul = (2/3)·(Δθ₁ × Δv₂ + Δv₁ × Δθ₂)

④ 旋转效应补偿
  Δv_rot = (1/2)·(Δθ × Δv)

⑤ 总速度增量（划桨 + 旋转均已补偿）
  Δv = Δv + Δv_scul + Δv_rot

⑥ 姿态更新 (用补偿后的 Δθ)
  q_new = q_old ⊗ axis_angle_to_quat(Δθ)

⑦ 速度更新 (用补偿后的 Δv)
  C = quat_to_dcm(q_old)           ← 用旧姿态！
  Δv_n = C @ Δv                     ← 补偿后的增量转到导航系
  v_new = v_old + Δv_n + g_n·dt     ← 加重力

⑧ 位置更新 (梯形积分)
  p_new = p_old + (v_old + v_new)·dt/2
```

### 双子样 vs 单子样的实际精度

在车载场景 (200 Hz, ~10 °/s 最大角速度, ~0.5g 振动):

| 误差项 | 单子样（不补偿） | 双子样（补偿后） |
|--------|:---:|:---:|
| 圆锥导致的航向漂移 | ~0.1 °/h | ~0.001 °/h |
| 划桨导致的速度偏差 | ~0.5 cm/s | ~0.001 cm/s |
| 位置漂移 (100 s) | ~0.5 m | ~1 mm |

**对于我们的 MVP 和教学目的**：
- MVP 阶段用 200 Hz 原始数据，单子样足够验证算法流程
- 如果要降采样到 100 Hz 做滤波（2 个 IMU 输出合并为 1 个导航历元），必须用双子样
- 代码接口预留 `n_subsamples` 参数，初值为 1，后续可扩展

## 误差状态动力学 —— P 矩阵如何传播（精确版）

这是 ESKF 最核心的数学推导。核心问题：
**标称状态用精密机械编排推了一步，15 维误差的协方差应该怎么变？**

### 连续时间误差状态方程

误差状态 δx 满足微分方程，每个分量逐项来看：

```text
(1) δṗ  = δv
    位置误差的变化 = 速度误差
    这很直接 — 速度估计错了，积分到位置就错了

(2) δv̇  = −C_b^n · [Δv×] · δθ           ← 姿态误差耦合（比力方向错了）
          + C_b^n · δb_a                 ← 加速度计偏置直接进入速度
          + C_b^n · n_a                  ← 加速度计白噪声
   
    "姿态搞错了 0.1° → 重力补偿的方向就偏了 → 错误的重力分量被积分 → 速度漂移"
    这是 INS 误差传播中最主要的项。

(3) δθ̇  = −C_b^n · δb_g                  ← 陀螺仪偏置 → 姿态误差积累
          − C_b^n · n_g                  ← 陀螺仪白噪声

(4) δḃ_a = n_ba                           ← 加速度计偏置 = 随机游走（缓慢漂移）

(5) δḃ_g = n_bg                           ← 陀螺仪偏置 = 随机游走
```

### F 矩阵的精确分块形式 (15×15)

写成 δẋ = F·δx + G·n_imu，F 的分块结构：

```text
     ┌                            ┐
     │ 0     I₃    0     0     0 │  ← δṗ = δv
     │                            │
F =  │ 0     0   −C[Δv×]  C     0 │  ← δv̇ = −C[Δv×]δθ + C·δb_a
     │                            │
     │ 0     0     0     0    −C │  ← δθ̇ = −C·δb_g
     │                            │
     │ 0     0     0     0     0 │  ← δḃ_a = 0 (纯噪声驱动)
     │                            │
     │ 0     0     0     0     0 │  ← δḃ_g = 0 (纯噪声驱动)
     └                            ┘

每块都是 3×3 子矩阵。C = C_b^n 每历元从当前姿态四元数重新计算。
```

**关键块 `−C[Δv×]` 的物理含义（最重要的一项）：**

```
[Δv×] 是 Δv 的反对称矩阵:
        ┌               ┐
        │  0   −Δv_z  Δv_y │
[Δv×] = │ Δv_z   0   −Δv_x │
        │ −Δv_y  Δv_x   0  │
        └               ┘

−C[Δv×]·δθ  的物理含义:

"如果我的姿态估计错了 δθ,
 我把 Δv 从 body 转到 nav 时就会用错误的姿态矩阵,
 导致错误的导航系速度增量。
 这个错误的导航系速度增量的大小
 ≈ −C·(Δv × δθ)"
```

### G 矩阵的分块形式 (15×12)

```text
     ┌                      ┐
     │ 0     0    0    0  │  ← δṗ 不受噪声直接影响
     │                     │
     │ C     0    0    0  │  ← 加速度计白噪声 → 速度
     │                     │
G =  │ 0    −C    0    0  │  ← 陀螺仪白噪声 → 姿态
     │                     │
     │ 0     0    I₃   0  │  ← 加速度计偏置随机游走
     │                     │
     │ 0     0    0    I₃ │  ← 陀螺仪偏置随机游走
     └                     ┘
```

### 离散化 —— Φ 矩阵的计算

连续时间 F → 离散时间 Φ 有多种算法：

**(A) 一阶近似（教学版·MVP 用此）**

```
Φ ≈ I + F·dt
```

优点：简单，200 Hz 下每个 dt 只有 5ms，一阶截断误差极小。

**(B) 矩阵指数（精确版）**

```
Φ = exp(F·dt) = I + F·dt + (F·dt)²/2! + (F·dt)³/3! + ...

F 的上三角结构意味着 (F·dt)ᵏ 对 k ≥ 4 很多块为零，
截断到 2 阶或 3 阶即可获得极高精度。
```

**(C) van Loan 方法（KF-GINS 采用, 同时获得 Φ 和 Q_d）**

构造增广矩阵并求矩阵指数：

```text
    ┌           ┐
A = │ −F   G·Qc·Gᵀ │
    │  0     Fᵀ    │
    └           ┘

exp(A·dt) = ┌           ┐
            │ *   Φ⁻¹·Qd │
            │ 0    Φᵀ   │
            └           ┘
```

这是"一次性同时得到 Φ 和离散化 Q_d"的标准方法。
对于教学项目，我们先用一阶近似 Φ = I + F·dt 验证逻辑，
精确版后续再做。

### 离散时间过程噪声 Q_d

```text
Q_c = diag(
    σ_a²·I₃,     ← 加速度计白噪声功率谱密度 [m²/s⁴/Hz]
    σ_g²·I₃,     ← 陀螺仪白噪声功率谱密度 [rad²/s²/Hz]
    σ_ba²·I₃,    ← 加速度计偏置随机游走驱动噪声 PSD
    σ_bg²·I₃     ← 陀螺仪偏置随机游走驱动噪声 PSD
)                                                                     (12×12)

一阶近似离散化:
Q_d ≈ Q_c · dt                                                        (12×12)

协方差传播:
P_pred = Φ @ P @ Φᵀ + G @ Q_d @ Gᵀ
```

### 连续时间误差状态方程

误差状态 `δx` 满足如下微分方程（推导见讲义）：

```text
δṗ  = δv                                            (1) 位置误差变化 = 速度误差
δv̇  = -C_b^n [Δv×] δθ + C_b^n δb_a + C_b^n n_a    (2) 速度误差变化 = 姿态耦合 + 偏置 + 噪声
δθ̇  = -C_b^n δb_g - C_b^n n_g                      (3) 姿态误差变化 = 陀螺偏置 + 噪声
δḃ_a = n_ba                                         (4) 偏置误差 = 随机游走
δḃ_g = n_bg                                         (5)
```

其中 `[Δv×]` 是速度增量 Δv 的反对称矩阵。

这写成矩阵形式就是：

```text
δẋ = F · δx + G · n_imu
```

其中 **F (15×15)** 是系统矩阵，**G (15×12)** 是噪声驱动矩阵。

### F 矩阵的分块结构 (15×15)

```text
     ┌                            ┐
     │ 0     I     0     0     0 │  ← δṗ
     │ 0     0  -C[Δv×]  C     0 │  ← δv̇
F =  │ 0     0     0     0    -C │  ← δθ̇
     │ 0     0     0     0     0 │  ← δḃ_a
     │ 0     0     0     0     0 │  ← δḃ_g
     └                            ┘

每块都是 3×3：

块(0,1) = I₃         → 位置误差的变化 = 速度误差
块(1,2) = -C[Δv×]    → 速度误差受姿态误差影响（"比力耦合"）
块(1,3) = C           → 速度误差受加速度计偏置影响
块(2,4) = -C          → 姿态误差受陀螺仪偏置影响
```

**关键观察**：
- 位置和速度误差互相耦合（位置→速度→姿态→偏置，逐级传递）
- 偏置本身只靠随机游走驱动（F 中偏置的行为零块）
- C = C_b^n 是当前姿态对应的 DCM，每步重新计算

### G 矩阵的分块结构 (15×12)

```text
     ┌                      ┐
     │ 0    0    0    0  │
     │ C    0    0    0  │    ← 加速度计白噪声 n_a 进入速度通道
G =  │ 0   -C    0    0  │    ← 陀螺仪白噪声 n_g 进入姿态通道
     │ 0    0    I    0  │    ← n_ba 进入加速度计偏置
     │ 0    0    0    I  │    ← n_bg 进入陀螺仪偏置
     └                    ┘
```

### 离散化

上述是连续时间的。实际每帧需要离散化：

```text
Φ = I + F · dt            ← 一阶近似 (Φ: 15×15 状态转移矩阵)

P_pred = Φ @ P @ Φ^T + G @ Q_d @ G^T
```

其中 `Q_d` 是离散时间过程噪声协方差 (12×12)：

```text
Q_d = diag(
    σ_a²·I₃·dt²,       ← 加速度计白噪声 (速度随机游走)
    σ_g²·I₃·dt²,       ← 陀螺仪白噪声 (角度随机游走)
    σ_ba²·I₃·dt,       ← 加速度计偏置随机游走
    σ_bg²·I₃·dt        ← 陀螺仪偏置随机游走
)
```

`dt²` vs `dt` 的区别：白噪声的方差和时间步长成正比，
而随机游走驱动的噪声方差和 dt² 成正比。这是因为：

```text
白噪声积分:  ∫ n·dt → 方差 ∝ dt²  → Q_d 中 × dt² (注: 实际简化处理)
随机游走:    ∫ n·dt → 方差 ∝ dt   → Q_d 中 × dt
```

(注：简化教学版统一使用 Q_d 的对角形式，精确版本需要积分推导)

## GNSS 松耦合更新

### 观测方程

GNSS RTK 直接给出 NED 位置（转换后）。对误差状态：

```text
z_gnss = p_ned_true + n_gnss           ← 观测 = 真值 + 噪声

残差 = z_gnss - p_nom                   ← 观测 - 标称位置 = 位置误差的观测

H = [I₃, 0₃, 0₃, 0₃, 0₃]             ← 只观测位置分量 (3×15)
```

### 标准卡尔曼更新

```text
S = H @ P @ H^T + R_gnss              ← 新息协方差
K = P @ H^T @ S^{-1}                   ← 卡尔曼增益 (15×3)

δx = K @ residual                      ← 计算误差状态的修正量
P = (I - KH) @ P                       ← 约瑟夫形式协方差更新
```

## 误差注入与重置 —— ESKF 独有的步骤

这是 ESKF 区别于普通 EKF 的关键操作。

### 注入 (Inject)

将估计出的误差加到标称状态上：

```text
p_nom  += δp             位置修正：直接加
v_nom  += δv             速度修正：直接加
q_nom  ←  q_nom ⊗ δq     姿态修正：右乘小角度四元数 δq = exp(δθ)
b_a    += δb_a           偏置修正：直接加
b_g    += δb_g           偏置修正：直接加
```

其中 `δq = [1, δθ_x/2, δθ_y/2, δθ_z/2]^T`（小角度近似，然后归一化）。

### 重置 (Reset)

注入后误差状态归零，但协方差 P 要做微小修正：

```text
δx = 0              ← 误差状态归零
P = J @ P @ J^T      ← 协方差投影到新的"零误差"切空间
```

重置的雅可比 J (15×15) 近似为单位矩阵，因为姿态误差重置时的
"gauge 变换"在小角度下近似为单位阵：`J ≈ I_15`。

教学版本可以简化为：**注入后 δx = 0, P 保持不变**（误差已经很小了）。

━━━ 主循环 (200 Hz) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    ┌─ update_gnss() + inject_reset() ──────────┐

    │                                           │
    │ ⑥ H = [I₃, 0₃, 0₃, 0₃, 0₃]               │
    │    K = P @ H^T @ (H @ P @ H^T + R)^(-1)   │
    │                                           │

    └───────────────────────────────────────────┘

    记录当前估计状态 (用于与真值对比)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

输出: 位置/速度/姿态 vs truth.nav → 计算 RMSE

## ESKF vs 普通 EKF 的对比

| | EKF (range-bearing) | ESKF (GNSS/IMU) |
|------|------|------|
| 状态 | 直接在 [px,py,vx,vy] 上滤波 | 标称状态 + 误差状态分离 |
| 标称状态传播 | f(x) — 恒定速度 | INS 机械编排 — 用 IMU 增量 |
| 误差状态传播 | — | F·δx, 在误差空间线性传播 |
| 协方差维度 | 4×4 | 15×15 (在 15 维误差状态上) |
| 线性化点 | 标称状态 | 误差状态 = 0 (总是最佳线性化点！) |
| 核心优势 | 简单 | 线性化更精确、姿态用四元数无奇点 |

## 常见错误

- 忘记每次 IMU step 后重新计算 C（DCM），用了旧的姿态矩阵
- 误差状态 δθ 的注入写成四元数加法而非乘法（四元数更新必须用乘法！）
- F 矩阵中忘记 `-C` 的负号
- 把 Δv（速度增量）当成加速度直接用，忘记除以 dt
- GNSS 和 IMU 的坐标系不一致（一个 WGS84，一个 NED），不转换直接减
- NED 坐标下重力是 [0, 0, +g]（向下为正），和 ENU 的 [0, 0, -g] 搞混
